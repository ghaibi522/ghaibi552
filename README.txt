X.ONE GAME PS4 HOST
====================
این نسخه یک صفحه برندینگ‌شده برای X.ONE GAME / فروشگاه شیرزاد است.

نکته:
- صفحه، ظاهر و نام X.ONE GAME را دارد.
- دکمه‌ها به Hostهای عمومی GamerHack متصل شده‌اند.
- برای 11.00، گزینه 7.00–13.00 به Host مربوطه می‌رود.
- پشتیبانی واقعی هر Firmware را باید قبل از انتشار نهایی بررسی کرد.
- برای GitHub Pages، فایل‌های index.html و style.css را در ریشه repository قرار دهید.
- اگر لوگوی PNG دارید، می‌توان آن را جایگزین لوگوی متنی داخل index.html کرد.
